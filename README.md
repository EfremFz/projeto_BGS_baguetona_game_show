# projeto_BGS_baguetona_game_show
## Projeto de gestão do campeonato 

---

Serão implementados as seguintes funções:

- Tela de cadastro de jogadores
- Tela de cadastro de jogos 
- Tela de cadastro de vantagens
- Painel para acompanhar classificação geral e quais jogadores estão jogando
- Tela de metres da tela
